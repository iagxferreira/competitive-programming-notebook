# 77. Combinations

leetcode | Medium | backtracking

## Task

Given two integers `n` and `k`, return all possible combinations of `k`
numbers chosen from the range `[1, n]`. You may return the answer in any
order.

`1 <= n <= 20`   `1 <= k <= n`
