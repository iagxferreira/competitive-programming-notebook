# 845. Longest Mountain in Array

leetcode | Medium | array, two-pointers, dynamic-programming, enumeration

## Task

An array is a mountain if its length is at least 3 and there is an index
`i` with `0 < i < arr.length - 1` such that `arr[0] < ... < arr[i]` and
`arr[i] > ... > arr[arr.length - 1]`. Given an integer array `arr`,
return the length of the longest subarray which is a mountain, or `0` if
there is none.

`1 <= arr.length <= 10^4`   `0 <= arr[i] <= 10^4`

Follow up: can you solve it in O(1) space and in one pass?
