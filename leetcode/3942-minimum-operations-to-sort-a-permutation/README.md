# 3942. Minimum Operations to Sort a Permutation

leetcode | medium | array, permutation

## Task

Given a permutation of `0` through `n - 1`, find the minimum number of
operations to sort it. An operation either reverses the entire array or
rotates it left by one. Return `-1` if sorting is impossible.
