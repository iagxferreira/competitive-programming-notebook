# 133. Clone Graph

leetcode | Medium | hash-table, depth-first-search, breadth-first-search

## Task

Given a reference of a node in a connected undirected graph.

Return a deep copy (clone) of the graph.

The number of nodes in the graph is in the range `[0, 100]`.   `1 <=
Node.val <= 100`   `Node.val` is unique for each node.   There are no
repeated edges and no self-loops in the graph.
