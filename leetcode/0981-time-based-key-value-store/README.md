# 981. Time Based Key-Value Store

leetcode | Medium | hash-table, string, binary-search

## Task

Design a time-based key-value data structure that can store multiple
values for the same key at different time stamps and retrieve the key's
value at a certain timestamp.

Implement the `TimeMap` class:

`1 <= key.length, value.length <= 100`   `key` and `value` consist of
lowercase English letters and digits.   `1 <= timestamp <= 10^7`   At
most `2 * 10^5` calls will be made to `set` and `get`.
