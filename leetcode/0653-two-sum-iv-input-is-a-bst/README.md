# 653. Two Sum IV - Input is a BST

leetcode | Easy | tree, binary-search-tree, hash-table, two-pointers

## Task

Given the `root` of a binary search tree and an integer `k`, return
`true` if there exist two elements in the BST such that their sum equals
`k`, or `false` otherwise.

The number of nodes is in the range `[1, 10^4]`.   `-10^4 <= Node.val <=
10^4`   The root is a valid BST.   `-10^5 <= k <= 10^5`
