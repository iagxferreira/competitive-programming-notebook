# 450. Delete Node in a BST

leetcode | Medium | tree, binary-search-tree, binary-tree

## Task

Given the `root` of a binary search tree and a `key`, delete the node
with the given key and return the root of the still-valid BST. If the
key does not exist, the tree is unchanged.

The number of nodes is in the range `[0, 10^4]`.   `-10^5 <= Node.val <=
10^5`   Each node has a unique value.   The root is a valid BST.
`-10^5 <= key <= 10^5`

Follow up: could you solve it with time complexity O(height of tree)?
