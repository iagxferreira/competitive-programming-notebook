# 211. Design Add and Search Words Data Structure

leetcode | Medium | string, depth-first-search, design

## Task

Design a data structure that supports adding new words and finding if a
string matches any previously added string.

Implement the `WordDictionary` class:

`1 <= word.length <= 25`   `word` in `addWord` consists of lowercase
English letters.   `word` in `search` consist of `'.'` or lowercase
English letters.   There will be at most `2` dots in `word` for `search`
queries.
