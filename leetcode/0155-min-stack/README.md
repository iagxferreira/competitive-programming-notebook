# 155. Min Stack

leetcode | Medium | stack, design

## Task

Design a stack that supports push, pop, top, and retrieving the minimum
element in constant time.

Implement the `MinStack` class:

`-2^31 <= val <= 2^31 - 1`   Methods `pop`, `top` and `getMin`
operations will always be called on non-empty stacks.   At most `3 *
10^4` calls will be made to `push`, `pop`, `top`, and `getMin`.
