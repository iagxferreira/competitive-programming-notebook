# 2236. Root Equals Sum of Children

leetcode | easy | trees

## Task

The tree consists of exactly three nodes: a root and its two children.
Return true if the root's value equals the sum of the two children's
values.

`root.left` and `root.right` are guaranteed to exist.
`-100 <= Node.val <= 100`
