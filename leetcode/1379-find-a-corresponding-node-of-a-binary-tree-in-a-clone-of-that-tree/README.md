# 1379. Find a Corresponding Node of a Binary Tree in a Clone of That Tree

leetcode | easy | trees, dfs

## Task

`cloned` is a structural copy of `original`. `target` is a reference to a
node in `original`. Return the reference to the CORRESPONDING node in
`cloned` — the one at the same position.

Up to 10^4 nodes. Values are NOT guaranteed unique — see the follow-up.
