# 409. Longest Palindrome

leetcode | easy | ?

## Task

Given a string `s`, return the length of the longest palindrome that can
be BUILT from its letters. You are rearranging, not finding a substring.

Letters are case sensitive — `"Aa"` is not a palindrome.
`1 <= s.length <= 2000`, English letters only.
