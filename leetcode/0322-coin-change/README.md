# 322. Coin Change

leetcode | Medium | array, dynamic-programming, breadth-first-search

## Task

You are given an integer array `coins` representing coins of different
denominations and an integer `amount` representing a total amount of
money.

Return the fewest number of coins that you need to make up that amount.
If that amount of money cannot be made up by any combination of the
coins, return `-1`.

`1 <= coins.length <= 12`   `1 <= coins[i] <= 2^31 - 1`   `0 <= amount
<= 10^4`
