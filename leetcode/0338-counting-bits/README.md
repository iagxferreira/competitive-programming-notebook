# 338. Counting Bits

leetcode | Easy | dynamic-programming, bit-manipulation

## Task

Given an integer `n`, return an array `ans` of length `n + 1` such that
for each `i` (`0 <= i <= n`), `ans[i]` is the number of `1`'s in the
binary representation of `i`.

Do not solve it with built-in functions (i.e., like `__builtin_popcount`
in C++).

`0 <= n <= 10^5`

Follow up: - It is very easy to come up with a solution with a runtime
of `O(n log n)`. Can you do it in linear time `O(n)` and possibly in a
single pass?
