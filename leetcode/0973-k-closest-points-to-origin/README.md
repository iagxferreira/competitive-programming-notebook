# 973. K Closest Points to Origin

leetcode | Medium | array, math, divide-and-conquer

## Task

Given an array of `points` where `points[i] = [x_i, y_i]` represents a
point on the X-Y plane and an integer `k`, return the `k` closest points
to the origin `(0, 0)`.

The distance between two points on the X-Y plane is the Euclidean
distance (i.e., `√(x_1 - x_2)^2 + (y_1 - y_2)^2`).

`1 <= k <= points.length <= 10^4`   `-10^4 <= x_i, y_i <= 10^4`
