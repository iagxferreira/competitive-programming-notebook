# 105. Construct Binary Tree from Preorder and Inorder Traversal

leetcode | Medium | array, hash-table, divide-and-conquer

## Task

Given two integer arrays `preorder` and `inorder` where `preorder` is
the preorder traversal of a binary tree and `inorder` is the inorder
traversal of the same tree, construct and return the binary tree.

`1 <= preorder.length <= 3000`   `inorder.length == preorder.length`
`-3000 <= preorder[i], inorder[i] <= 3000`   `preorder` and `inorder`
consist of unique values.
