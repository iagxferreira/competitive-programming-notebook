# 700. Search in a Binary Search Tree

leetcode | easy | trees, binary-search

## Task

Find the node whose value is `val` and return the SUBTREE rooted at it,
not just the node's value. Return null if no such node exists.

Node values are unique. `1 <= Node.val <= 10^7`, up to 5000 nodes.
