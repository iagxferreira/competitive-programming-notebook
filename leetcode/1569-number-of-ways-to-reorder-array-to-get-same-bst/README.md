# 1569. Number of Ways to Reorder Array to Get Same BST

leetcode | hard | combinatorics, binary-search-tree

## Task

Count the reorderings of `nums` that produce the same BST as the original
ordering. Do not count the original ordering; return the answer modulo
`10^9 + 7`.

`1 <= nums.length <= 1000`; all values are distinct.
