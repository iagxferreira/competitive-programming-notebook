# 207. Course Schedule

leetcode | Medium | depth-first-search, breadth-first-search, graph

## Task

There are a total of `numCourses` courses you have to take, labeled from
`0` to `numCourses - 1`. You are given an array `prerequisites` where
`prerequisites[i] = [a_i, b_i]` indicates that you must take course
`b_i` first if you want to take course `a_i`.

Return `true` if you can finish all courses. Otherwise, return `false`.

`1 <= numCourses <= 2000`   `0 <= prerequisites.length <= 5000`
`prerequisites[i].length == 2`   `0 <= a_i, b_i < numCourses`
