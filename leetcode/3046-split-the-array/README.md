# 3046. Split the Array

leetcode | easy | arrays, counting

## Task

Given an integer array `nums` of **even** length, split it into two parts
`nums1` and `nums2` such that:

- `nums1.length == nums2.length == nums.length / 2`
- `nums1` contains **distinct** elements
- `nums2` contains **distinct** elements

Return `true` when such a split exists, `false` otherwise.

`[1,1,2,2,3,4]` is `true` — for example `nums1 = [1,2,3]`,
`nums2 = [1,2,4]`. `[1,1,1,1]` is `false`.

`1 <= nums.length <= 100`   `nums.length % 2 == 0`   `1 <= nums[i] <= 100`

Note that you are only asked **whether** a split exists, not to produce
one.
