# 1200. Minimum Absolute Difference

leetcode | Easy | array, sorting

## Task

Given an array of distinct integers `arr`, find all pairs of elements
with the minimum absolute difference of any two elements. Return the
pairs in ascending order, each pair `[a, b]` with `a < b` and `b - a`
equal to the minimum absolute difference of any two elements in `arr`.

`2 <= arr.length <= 10^5`   `-10^6 <= arr[i] <= 10^6`
