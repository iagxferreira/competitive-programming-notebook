# 701. Insert into a Binary Search Tree

leetcode | Medium | tree, binary-search-tree, binary-tree

## Task

You are given the `root` of a binary search tree and a `value` to
insert. Insert the value into the BST and return the root of the tree.
The new value does not exist in the original BST. Any valid insertion
that keeps the BST property is accepted.

The number of nodes is in the range `[0, 10^4]`.   `-10^8 <= Node.val <=
10^8`   All values are unique.   `-10^8 <= val <= 10^8`
