# 127. Word Ladder

leetcode | Hard | hash-table, string, breadth-first-search

## Task

A transformation sequence from word `beginWord` to word `endWord` using
a dictionary `wordList` is a sequence of words `beginWord -> s_1 -> s_2
-> ... -> s_k` such that:

- Every adjacent pair of words differs by a single letter.

`1 <= beginWord.length <= 10`   `endWord.length == beginWord.length`
`1 <= wordList.length <= 5000`   `wordList[i].length ==
beginWord.length`
