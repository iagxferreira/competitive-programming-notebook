# 73. Set Matrix Zeroes

leetcode | Medium | array, hash-table, matrix

## Task

Given an `m x n` integer matrix `matrix`, if an element is `0`, set its
entire row and column to `0`'s.

You must do it in place.

`m == matrix.length`   `n == matrix[0].length`   `1 <= m, n <= 200`
`-2^31 <= matrix[i][j] <= 2^31 - 1`

Follow up: - A straightforward solution using `O(mn)` space is probably
a bad idea. - A simple improvement uses `O(m + n)` space, but still not
the best solution. - Could you devise a constant space solution?
