# 435. Non-overlapping Intervals

leetcode | Medium | array, dynamic-programming, greedy

## Task

Given an array of intervals `intervals` where `intervals[i] = [start_i,
end_i]`, return the minimum number of intervals you need to remove to
make the rest of the intervals non-overlapping.

Note that intervals which only touch at a point are non-overlapping. For
example, `[1, 2]` and `[2, 3]` are non-overlapping.

`1 <= intervals.length <= 10^5`   `intervals[i].length == 2`   `-5 *
10^4 <= start_i < end_i <= 5 * 10^4`
