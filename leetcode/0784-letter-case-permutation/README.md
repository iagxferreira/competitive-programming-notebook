# 784. Letter Case Permutation

leetcode | Medium | string, backtracking, bit-manipulation

## Task

Given a string `s`, transform every letter individually to be lowercase
or uppercase to create another string. Return a list of all possible
strings we could create, in any order.

`1 <= s.length <= 12`   `s` consists of lowercase English letters,
uppercase English letters and digits.
