# 112. Path Sum

leetcode | Easy | tree, depth-first-search, binary-tree

## Task

Given the `root` of a binary tree and an integer `targetSum`, return
`true` if the tree has a root-to-leaf path such that adding up all the
values along the path equals `targetSum`. A leaf is a node with no
children.

The number of nodes is in the range `[0, 5000]`.   `-1000 <= Node.val <=
1000`   `-1000 <= targetSum <= 1000`
