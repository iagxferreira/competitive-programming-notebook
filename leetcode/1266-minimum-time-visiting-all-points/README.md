# 1266. Minimum Time Visiting All Points

leetcode | Easy | array, math, geometry

## Task

On a 2D plane there are `n` points with integer coordinates `points[i] =
[xi, yi]`. Return the minimum time in seconds to visit all the points in
the order given. In one second you can move one unit vertically,
horizontally, or diagonally; you must visit the points in the same order
as they appear.

`points.length == n`   `1 <= n <= 100`   `points[i].length == 2`
`-1000 <= points[i][0], points[i][1] <= 1000`
