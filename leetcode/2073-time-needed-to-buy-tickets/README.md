# 2073. Time Needed to Buy Tickets

leetcode | Easy | array, queue, simulation

## Task

There are `n` people in a queue, where `tickets[i]` is the number of
tickets person `i` wants to buy. Buying one ticket takes one second, and
a person at the front who still needs more tickets goes to the back of
the line after each purchase; a person leaves the line once they have
bought all their tickets. Return the time taken for the person at
position `k` to finish buying all their tickets.

`n == tickets.length`   `1 <= n <= 100`   `1 <= tickets[i] <= 100`   `0
<= k < n`
