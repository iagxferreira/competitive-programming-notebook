# 733. Flood Fill

leetcode | Easy | array, depth-first-search, breadth-first-search

## Task

You are given an image represented by an `m x n` grid of integers
`image`, where `image[i][j]` represents the pixel value of the image.
You are also given three integers `sr`, `sc`, and `color`. Your task is
to perform a flood fill on the image starting from the pixel
`image[sr][sc]`.

To perform a flood fill:

`m == image.length`   `n == image[i].length`   `1 <= m, n <= 50`   `0 <=
image[i][j], color < 2^16`
