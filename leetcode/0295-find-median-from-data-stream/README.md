# 295. Find Median from Data Stream

leetcode | Hard | two-pointers, design, sorting

## Task

The median is the middle value in an ordered integer list. If the size
of the list is even, there is no middle value, and the median is the
mean of the two middle values.

Implement the MedianFinder class:

`-10^5 <= num <= 10^5`   There will be at least one element in the data
structure before calling `findMedian`.   At most `5 * 10^4` calls will
be made to `addNum` and `findMedian`.

Follow up: - If all integer numbers from the stream are in the range
`[0, 100]`, how would you optimize your solution? - If `99%` of all
integer numbers from the stream are in the range `[0, 100]`, how would
you optimize your solution?
