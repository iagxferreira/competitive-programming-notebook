# 203. Remove Linked List Elements

leetcode | Easy | linked-list, recursion

## Task

Given the `head` of a linked list and an integer `val`, remove all the
nodes of the linked list that have `Node.val == val`, and return the new
head.

The number of nodes is in the range `[0, 10^4]`.   `1 <= Node.val <= 50`
`0 <= val <= 50`
