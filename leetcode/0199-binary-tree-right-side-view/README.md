# 199. Binary Tree Right Side View

leetcode | Medium | tree, depth-first-search, breadth-first-search

## Task

Given the `root` of a binary tree, imagine yourself standing on the
right side of it, return the values of the nodes you can see ordered
from top to bottom.

The number of nodes in the tree is in the range `[0, 100]`.   `-100 <=
Node.val <= 100`
