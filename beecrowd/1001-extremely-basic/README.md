# 1001. Extremely Basic

beecrowd | trivial | io

## Task

Read two integers A and B, print `X = ` followed by their sum.

## Key insight

The label is part of the answer. Beecrowd's early set is really a
formatting exam wearing an arithmetic costume.

## Invariant

None.

## Complexity

time O(1)   space O(1)

## Pitfall

`X = 5`, not `X=5` and not `5`. Spaces around the equals sign are graded.
