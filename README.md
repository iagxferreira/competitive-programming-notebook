# Competitive Programming Practice

This repository is my personal space to practice competitive programming,
solve problems, and get better at C++.

## Problems

Problems are grouped by platform. Each problem has its own folder, with a
solution and any notes or test cases kept alongside it.

```text
leetcode/<number>-<problem-name>/
codeforces/<number>-<problem-name>/
hackerrank/<problem-name>/
beecrowd/<number>-<problem-name>/
```

C++ is my focus going forward. Older solutions in other languages are kept as
part of the repository's history; new practice will be organized around C++.
